## Open questions answered

- **Does Draw (`sub_82123758`) advance game state?** No. In a split-screen
  battle the round timer ran in real time (81.19 → 68.83 over about 12 s).
  Draw only bumps a frame counter at `this+12`, renders and presents.
- **Draw's arguments:** only `r3` (`this`). Restoring the full context, as
  handoff fix #5 does, is still harmless.

## Bugs found and fixed during testing

1. **The split-screen speed fix leaked into the saved config.** The game set
   `guest_vblank_multiplier` with `SetFlagByName`, and `SaveConfig` writes
   every non-default value. Saving settings during a split battle stored `= 2`,
   so later sessions ran the menus at double speed. The owner's config already
   had it.
   - Fix: a runtime-only `split_screen::SetVblankMultiplier()` in the SDK; the
     vsync thread uses the higher of that and the cvar.
   - The owner's config was cleaned.
2. **Split screen and player-2 control did nothing in Training.** Training
   battles run in module 2 (NETVS), not 1. Battle is now module 1 or 2
   (`IsBattleModule`).
3. **`SaveConfig` also saved command-line flags** such as `--log_file` from
   `run.bat`, `--mnk_mode`, and test switches.
   - Fix: the F1 menu and Alt+Enter now use `oratan::SaveSettings`
     (`src/settings.cpp`), which only updates the five player-facing settings
     and keeps the rest of the file.
   - The SDK's own F4 overlay still uses `SaveConfig`.

## Other handoff items done

- **Garbage first frame:** the composite is only published once every view has
  been drawn into it since splitting started. The tracking is reset on any
  untagged swap and when the textures are recreated. The final copy into the
  presenter's image uses `CopyTextureRegion` with an explicit box. (SDK, in
  `0002-split-screen.patch`.)
- **Turning player-2 control off mid-match** hands the robot back to the CPU.
  Verified in Arcade: the AI resumed attacking within seconds. Flags are only
  touched in battle, and the "switched" log line appears once per match, not
  every frame.
- **FPS log in split screen** now counts game ticks (60), not presents (120).
- **Game file search** skips unreadable folders
  (`skip_permission_denied`) instead of stopping.
